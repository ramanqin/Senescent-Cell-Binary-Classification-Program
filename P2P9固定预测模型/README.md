# P2/P9 固定预测模型

这里放的是此前用 P2 年轻组 53 个编号、P9 衰老组 38 个编号训练的三个最终模型：PCA-SVM、PCA-逻辑回归和随机森林。开发时做过固定参数的普通分层 5 折验证；打包的 `joblib` 是随后使用全部 91 个训练编号拟合的最终版本，不是某一折的模型。参数在此前同一批 P2/P9 分析中有过选择，因此普通 5 折成绩不能视为完全独立的模型选择验证。运行 `预测新数据.py` 只做预测，不会用新数据重新训练、重新拟合 PCA 或调整判别阈值。

## 这个文件夹里有什么

- `模型文件/`：三个固定模型。SVM 和逻辑回归文件中已包含 PCA 等训练好的处理环节。
- `预测新数据.py`：读取新批次预处理光谱，按编号求平均，然后调用三个模型。
- `raman_io.py`：两列 TXT 光谱的读取函数。
- `预处理参数.json`：训练数据所用的光谱批处理参数，供核对。
- `模型清单.json`：类别编码、模型文件校验值和评分含义。
- `requirements.txt`：预测脚本的 Python 依赖。

## 输入是什么

不能把原始光谱直接放进预测程序。先按项目 `data analysis` 的流程做光谱清洗和批处理预处理；使用与 `预处理参数.json` 相同的设置，特别是 **600–1800 cm⁻¹、步长 1 cm⁻¹、共 1201 个数值点**，以及宇宙射线处理、ALS 基线、SG 平滑和向量归一化。每条预处理 TXT 为两列数字：波数、强度；可以带本项目批处理默认的一行表头。程序会检查波数轴，但不能仅凭文件判断前面的全部清洗和预处理是否正确完成。

已知标签的外部测试可这样放：

```text
预处理光谱/
├─ 年轻/
│  ├─ 编号01/光谱1.txt
│  └─ 编号02/光谱1.txt
└─ 衰老/
   └─ 编号03/光谱1.txt
```

真正不提供标签的预测则这样放：

```text
预处理光谱/
├─ 编号01/
│  ├─ 光谱1.txt
│  └─ 光谱2.txt
└─ 编号02/光谱1.txt
```

同一编号可放多条通过质控的光谱。程序先求平均，每个编号只产生一条预测；不要把同一编号的多条谱当作多个独立样本。输入目录中不要混用有标签和无标签两种结构。

## 怎么运行

建议使用 Python 3.11 或以上。`requirements.txt` 固定了已测试的 scikit-learn 1.9.0，以便加载保存好的模型。进入本文件夹后运行：

```powershell
python -m pip install -r requirements.txt
python .\预测新数据.py --input "D:\你的预处理光谱" --output "D:\P2P9预测结果"
```

省略 `--output` 时，结果会写到输入目录旁边的 `输入目录名_P2P9预测结果`。输出包括 `逐编号预测.csv`、`预测汇总.json` 和 `运行核查.json`。有标签时汇总文件还会计算准确率、两组识别率、平衡准确率和 AUC；无标签时只给预测，不会虚构准确率。`衰老评分` 在 SVM 中是决策值，不是概率；在逻辑回归和随机森林中是模型给出的衰老类概率。三种评分不能直接横向比较。

## 使用前要知道的限制

P2 年轻组文件名中的采集设置为 12.0 mW、6.000 s，P9 衰老组为 13.0 mW、2.000 s，**训练数据里采集条件与标签完全重合**。因此模型可能利用了采集差异，原有 5 折成绩不能证明它在新批次中只识别细胞状态。直接外测 P6 时，三个固定模型将 44 个编号全部判为年轻；P6 两组都采用 12.0 mW、6.000 s。这是重要的适用性警告，不能把本模型当作已验证可靠的独立诊断工具。

模型文件来自本项目此前的 P2/P9 分析结果，仅应从可信来源加载 `joblib` 文件。若更换预处理方式、波数范围或训练样本，应该重新建立并验证模型；不要只改本文件夹里的参数说明。
