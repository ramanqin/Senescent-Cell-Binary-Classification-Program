# PCA-SVM分类

## 方法

- 分析单位：受试者级平均光谱，共98人（年轻60、衰老38）。
- 外层5折交叉验证评价性能，内层4折选择参数。
- PCA保留95%方差，随后标准化并训练SVM；PCA和标准化均在训练折内部拟合。
- 内层比较线性核、RBF核、C和gamma。

## 当前结果

- AUC、准确率和平衡准确率均为1.000。
- TN=60、FP=0、FN=0、TP=38。
- 五折均选择线性核和C=0.01。

## 运行

```bash
pip install -r 代码/requirements.txt
python 代码/run_classification.py --input 数据目录 --output 新结果 --models svm --negative-class 年轻 --positive-class 衰老
```

`代码`中包含数据读取与分类程序，`结果`中包含指标、逐例预测、每折参数、ROC和混淆矩阵。
