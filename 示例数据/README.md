# 演示数据

`原始光谱`和`已预处理光谱`由本目录的`生成演示数据.py`生成。它们是人为构造的信号，不是细胞实验数据，组别差异也由程序刻意加入。这里只用它们检查目录、清洗、预处理、分类和差异分析能否接起来；任何准确率、p 值、峰位归属都没有科研含义。

- `原始光谱`：年轻和衰老各 5 个编号，每个编号 2 条原始 TXT；覆盖 500–3300 cm⁻¹。按目前默认清洗规则，演示文件应全部通过。
- `已预处理光谱`：同一批信号经项目批处理核心函数按默认参数处理后的对应文件；覆盖 600–1800 cm⁻¹，步长 1，共 1201 个数值点。文件有批处理程序默认的一行表头。
- `生成演示数据.py`：留作生成方式记录；不会在打开项目时自动运行。它拒绝覆盖已存在的演示光谱目录。

从项目根目录照着[快速开始](../快速开始.md)运行。若改了清洗或预处理程序，演示数据不再能代表新代码的输出；先在独立目录重新生成，再核对差异。不要用演示数据训练需要对外发布的模型。
