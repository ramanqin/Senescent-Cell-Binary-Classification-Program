# 光谱批处理与预处理

这个程序处理双列 TXT、CSV、DAT 光谱。常用顺序是先做光谱清洗，再把清洗结果中的 `passed/` 作为这里的输入。程序可以截取波段、修复宇宙射线、校正基线、平滑和归一化，并保留原来的子目录层级。

## 启动

Windows 可依次双击 `安装依赖.bat`、`启动软件.bat`。也可以在本目录运行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

在界面里选择输入、输出文件夹，先预览几条谱，再运行批处理。输出会放在新的 `preprocessing_run_时间/` 下；处理报告、`run_manifest.csv` 和 `run_parameters.json` 可用于核对成功/失败文件与实际使用参数。程序不改原始光谱。

默认输出 TXT，第一行是 `Raman_shift_cm-1`、`Intensity` 表头，后面才是数值行。保持“保留输入目录结构”开启，下游才能继续按 `年轻/个体编号`、`衰老/个体编号` 读取。项目中的分类、固定模型预测和差异分析入口均可读取这一默认表头。

## 文件分工

| 文件 | 用途 |
|---|---|
| `app.py` | 桌面界面、参数载入与保存、预览和批处理任务。 |
| `spectral_preprocessor.py` | 读谱、裁剪波段、宇宙射线处理、重采样、基线校正、SG 平滑、归一化和写出结果。`PreprocessConfig` 也定义在这里。 |
| `test_fixed_step.py` | 检查步长 1 的固定行为和旧参数文件兼容。 |
| `test_file_discovery.py` | 检查目录扫描、清单和结果目录排除逻辑。 |

`默认参数.json` 是可载入的参数样例；`固定版说明.md` 解释了步长 1 的限制。两个 `.bat` 分别安装依赖和启动界面。

## 参数在哪改

在界面的“预处理参数”页调整，使用“保存参数”写出 JSON，下一次用“载入参数”恢复。默认值来自 `spectral_preprocessor.py` 的 `PreprocessConfig`，随包提供的配置在 `默认参数.json`。若要修改软件初始默认值，需要同步检查这两处。

当前版本强制开启重采样，步长固定为 **1 cm⁻¹**；界面中该项只读，载入旧 JSON 时也会改为 1。`600-1800` 区间在原谱完整覆盖时得到 1201 个点。其它主要默认设置：ALS 基线（λ=100000、p=0.01、15 次迭代）、SG 7 点 2 阶、向量归一化。波段、宇宙射线阈值、基线、SG 和归一化方式仍可调整。更密的插值不会增加仪器的实际分辨率。
