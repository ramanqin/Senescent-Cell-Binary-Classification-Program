# PCA降维

## 方法

对98名受试者的平均光谱进行无监督PCA。年轻/衰老标签只用于散点着色，不参与PCA拟合。

## 当前结果

- PC1解释58.72%的总变异。
- PC2解释13.45%的总变异。
- 前两维累计解释72.17%。
- 两组中心明显偏移，但二维空间仍存在部分重叠。

## 运行

```bash
pip install -r 代码/requirements.txt
python 代码/visualize_embeddings.py --input 数据目录 --output 新结果 --negative-class 年轻 --positive-class 衰老
```

程序会同时生成PCA和t-SNE文件。本文件夹的`结果`仅保留PCA二维坐标、解释方差和得分图。
