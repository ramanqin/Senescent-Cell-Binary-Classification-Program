# t-SNE降维

## 方法

先用PCA保留95%方差（当前为12个成分），标准化后运行二维t-SNE。主参数为perplexity=20、随机种子42，并比较perplexity=10、20、30。

## 当前结果

- perplexity=20时，按年龄标签计算的二维轮廓系数为0.441。
- 三个perplexity设置下均可观察到明显组间结构。
- t-SNE使用全部样本共同生成坐标，因此只用于探索性展示，不作为独立交叉验证成绩。

## 运行

```bash
pip install -r 代码/requirements.txt
python 代码/visualize_embeddings.py --input 数据目录 --output 新结果 --negative-class 年轻 --positive-class 衰老 --perplexity 20 --seed 42
```

`结果`中包含二维坐标、参数敏感性表、SVM-tSNE展示图和参数敏感性图。
