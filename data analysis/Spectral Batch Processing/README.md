# 拉曼光谱批量预处理软件

这是一个带简易桌面前端的批量光谱预处理工具，支持TXT、CSV和DAT双列光谱。

## 启动方法

1. 安装Python 3.10或更高版本，并在安装时勾选“Add Python to PATH”。
2. 首次使用双击`安装依赖.bat`。
3. 双击`启动软件.bat`。

也可以在命令行运行：

```powershell
python -m pip install -r requirements.txt
python app.py
```

## 主要功能

- 递归读取TXT、CSV、DAT光谱；
- 自动跳过表头和非数值行；
- 支持多个波数区间，例如`600-1800,2700-3600`；
- 局部中位数与MAD宇宙射线检测和插值修复；
- ALS、airPLS、多项式基线校正；
- Savitzky–Golay平滑以及一阶、二阶导数；
- 向量、面积、SNV、Min-Max归一化；
- 分波段固定步长重采样；
- 原始光谱与预处理结果预览；
- 参数保存、载入；
- 批处理进度、停止功能和CSV处理报告；
- 可保留原始子目录结构，不修改原始文件。

## 推荐的首次参数

对P4和P7原始数据完成001清洗和全量复查后，建议使用：

| 项目 | 建议值 |
|---|---|
| 波数范围 | `600-1800` |
| 重采样 | 开启，公共网格步长`3 cm⁻¹` |
| 宇宙射线窗口 | 5 |
| 宇宙射线动态因子 | 12 |
| 最大峰宽 | 3个采样点 |
| 基线 | ALS |
| ALS λ | 100000 |
| ALS p | 0.01 |
| 迭代次数 | 15 |
| SG窗口 | 7 |
| SG多项式阶数 | 2 |
| SG导数 | 0 |
| 归一化 | 向量归一化 |

建议先预览几条光谱，确认基线未被过度扣除、峰形未被明显抹平，再批量运行。

P7清洗合格光谱中存在两套相互错开约`1.41 cm⁻¹`的原始波数网格。若关闭重采样，文件虽都有412个点，但同一列不一定代表同一波数，直接用于PCA或分类可能引入假差异。采用`600–1800 cm⁻¹`、步长`3 cm⁻¹`后，P4和P7均输出401个严格对应的波数点；该步长也接近原始采样间隔约`2.91 cm⁻¹`，不会造成无意义的过度插值。

## 参数说明

### 宇宙射线

- `窗口`：局部中位数窗口，必须是奇数；一般使用5或7。
- `阈值`：当前点偏离局部中位数达到多少倍MAD时判为异常；越低越敏感。
- `最大峰宽`：只修复不超过该宽度的尖峰，避免把正常拉曼峰当成宇宙射线。
- `迭代`：用于处理同一光谱中的多个异常尖峰。

### 基线

- ALS的λ越大，基线越平滑。P7参数比较后采用`100000`；若数据尺度或采样间隔改变，应通过预览重新检查。
- ALS的p控制不对称程度，常用`0.001–0.05`。
- airPLS不需要p，但仍使用λ和迭代次数。
- 多项式基线适合形状较简单的背景，不建议使用过高阶数。

### SG平滑

- 窗口必须是奇数，并且大于多项式阶数。
- 窗口越大越平滑，也越容易削弱窄峰。
- 导数0表示只平滑；导数1或2用于增强峰形，但会增加噪声敏感性。

### 归一化

- 向量归一化：适合作为默认方案。
- 面积归一化：适合整体面积有可比意义的光谱。
- SNV：减少整体偏移和尺度差异。
- Min-Max：统一到0–1，但对极端峰较敏感。

## 输出内容

软件不会改动原始文件。输出目录中包含：

- 处理后的双列光谱；
- `处理报告_时间.csv`：记录成功、失败、修复点数和错误原因；
- 报告同时记录起止波数和中位步长，便于核对不同文件是否位于同一网格；
- `本次参数_时间.json`：保证分析可以复现。

## 注意事项

- 不要把输出目录设置为输入目录本身。
- 批次效应不能仅靠光谱预处理消除；建模仍应按实验批次进行交叉验证。
- 不要在测试集上单独调参。正式建模时，参数应由训练数据确定后固定应用于测试数据。
