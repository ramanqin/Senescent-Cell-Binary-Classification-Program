# PCA-逻辑回归分类

## 方法

- 分析单位：受试者级平均光谱，共98人。
- 外层5折评价，内层4折选择C和L1/L2/Elastic Net混合比例。
- PCA保留95%方差，随后标准化并训练正则化逻辑回归；全部步骤位于交叉验证训练折内部。

## 当前结果

- AUC、准确率和平衡准确率均为1.000。
- TN=60、FP=0、FN=0、TP=38。
- 五折均选择C=0.001、l1_ratio=0，即强L2正则化。

## 运行

```bash
pip install -r 代码/requirements.txt
python 代码/run_classification.py --input 数据目录 --output 新结果 --models logistic --negative-class 年轻 --positive-class 衰老
```

`代码`中包含数据读取与分类程序，`结果`中包含指标、逐例预测、每折参数、ROC和混淆矩阵。
