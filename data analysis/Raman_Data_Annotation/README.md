# Raman Data Annotation

这是基于 `002_Raman_Spectrum_Plot_Marking` 改写的抽样标注版。它可以从任意文件夹递归查找TXT，再抽取一部分进行人工质量标注。它不负责训练 `young/aging` 分类器。

## 输入文件夹

默认读取 `D:\raw_data`，但界面中可以选择任意文件夹，例如：

```text
D:\raw_data                       # 全部数据
D:\raw_data\young                # 只从年轻组抽样
D:\raw_data\aging                # 只从衰老组抽样
D:\raw_data\aging\10             # 只从一个个体抽样
D:\other_experiment               # 任意其他TXT文件夹
```

程序递归读取所选文件夹及其全部子文件夹中的 `*.txt`，不会修改原始文件。路径中存在 `young/aging/<subject_id>` 时会自动解析类别和个体；普通文件夹无法识别时保存为 `class_original=unknown`、`subject_id=TXT所在文件夹名`。

## 分组编码与抽样设置

本项目统一使用以下编码：

```text
0 = young（年轻）
1 = aging（衰老）
```

界面分别设置每组配额：

- `0组（年轻 young）`：默认50条。
- `1组（衰老 aging）`：默认50条。
- `未知组`：默认0条；仅用于没有可识别组别目录的普通文件夹。
- 每组填写`-1`表示使用该组全部光谱，填写`0`表示不抽该组。
- 如果所选文件夹中没有某一组，该组自动得到0条，不影响已有组抽样。
- `balanced`：在每个组内部轮流覆盖不同个体，推荐用于当前数据。
- `random`：在每个组内部做简单随机抽样。
- 随机种子：相同文件夹、数量、方式和种子会得到完全相同的样本，便于继续标注。
- 抽样清单会随每行CSV记录 `selected_folder`、`sampling_strategy`、`sampling_seed` 和 `sample_order`。
- 第一次加载时会在标注CSV旁生成 `<文件名>_sample_manifest.csv`，立即固定全部抽样名单。以后使用同一标注CSV继续时会直接恢复这份名单，不会重新抽样；若要开始新的抽样，请选择一个新的标注CSV文件名。

## 启动

双击 `Raman_Data_Annotation.bat`，或在本目录运行：

```powershell
python __main__.py
```

只检查数据结构、不打开界面：

```powershell
python __main__.py --scan --data D:\raw_data --group0-size 50 --group1-size 50 --unknown-size 0 --strategy balanced --seed 20260813
```

默认标注结果保存到：

```text
D:\raman_annotation_results\raman_qc_annotations_group01.csv
```

若该CSV已经存在，点击“加载/继续标注”会自动跳到下一条未标注光谱。

## 标注规则

- `PASS`：没有选中任何异常原因。
- `REVIEW`：边界情况，必须至少选择一个异常原因。
- `FAIL`：明确不合格，必须至少选择一个异常原因。
- 一个光谱可以有多个异常原因。
- 默认隐藏组别和个体，以盲法顺序显示；需要核对身份时可勾选“显示组别与个体”。
- 橙色SG曲线只辅助观察噪声，不改变原始TXT，也不作为清洗后的正式光谱。

## 整体预筛与决策树辅助

整体预筛原先已经包含点数、波数最小/最大值、步长、强度统计、稳健SNR、尖峰、饱和、缺失值及波数轴状态，并非只看最大值和最小值。本版进一步增加并在界面显示：

- 强度P05、中位数和P95；
- P95−P05稳健动态范围；
- 静默区稳健噪声；
- 指纹区及C–H区对比度（写入CSV，供辅助分析）；
- 非缺失比例、饱和连续点和波数轴状态。

程序还会根据已经保存的人工QC标注训练一个限制深度的决策树：

- 总人工标注少于30条时不训练；
- `PASS`和`REVIEW/FAIL`两类中任一类少于8条时不训练；
- 只使用技术质量指标，不使用0/1疾病类别、个体编号或文件路径；
- 只输出`建议PASS`、`建议人工关注`或`不确定`；
- 只有PASS概率达到90%时才启用“采用高置信PASS建议”按钮；
- 采用建议只填入PASS，不自动保存，最终结论仍由标注人员负责。

指纹峰及C–H峰的高低可能包含真实健康/衰老生物差异，因此不能依据这些数值设置硬性自动剔除阈值。决策树建议不能替代人工QC，也不能用来生成最初一批训练标签。

## 四幅光谱图的含义

- 左上“全波段”：显示完整拉曼范围，用于总体观察基线、荧光背景、饱和削顶、平坦谱、异常大峰和全局形态。
- 右上“指纹区 500–1800 cm⁻¹”：包含较丰富的蛋白质、脂质、核酸等分子振动信息，用于判断主要峰是否清晰、缺失或过低。
- 左下“静默区 1800–2700 cm⁻¹”：一般生物拉曼峰较少，主要用于观察噪声、宇宙射线尖峰和异常背景；不是要求曲线绝对水平。
- 右下“C–H伸缩区 2700–3200 cm⁻¹”：观察脂质和蛋白等C–H伸缩振动形成的宽峰是否存在、是否过低或形态异常。
- 蓝线为原始光谱，是人工QC的主要依据；橙线为Savitzky–Golay平滑预览，只帮助区分真实宽峰与高频噪声。

快捷键：

- `P`：设为`PASS`，并清除已经勾选的异常原因；
- `F`：设为`FAIL`；保存前还需至少选择一个异常原因；
- 数字键`2`～`8`：勾选或取消对应异常原因，再按一次可取消；
- 数字键`1`：不使用；
- `←`：返回上一条谱图；
- `→`：保存当前标注并进入下一条未标注谱图；
- `Ctrl+S`：仅保存当前标注；
- `Ctrl+←`、`Ctrl+→`：备用的上一条/保存并下一条快捷键。

异常原因的数字键对应关系为：`2`指纹峰模糊、`3`指纹峰丢失、`4`指纹峰强度低、`5`信噪比低、`6`碳氢峰丢失、`7`碳氢峰强度低、`8`存在宇宙射线。`REVIEW`仍通过鼠标选择。

当光标位于路径、抽样数量、随机种子等输入框时，字母、数字和普通左右方向键都用于正常输入，不触发QC或谱图切换。点击光谱图、QC选项或界面空白处后，快捷键即可生效。

操作按钮位于QC区域右侧，不再放在窗口最下方；程序启动时默认最大化到Windows任务栏上方的可用工作区。界面已删除自由备注输入框；CSV中的`other_mark`列仅为兼容早期结果而保留为空。

## 输出信息

CSV每行对应一条光谱，包含：

- `class_original`、`class_binary`、`subject_id`、`spectrum_no`
- 原始绝对/相对路径、TIF和PNG关联路径
- `pass/review/fail`及7种可多选异常原因
- 点数、波数范围、强度分位数、稳健动态范围、分区对比度、静默区噪声、稳健SNR、自动尖峰数和波数轴状态
- 标注时间和工具版本

训练二分类时必须使用 `subject_id` 作为分组字段，不能随机拆分同一个体的50条光谱。

## 当前数据验证结果

对 `D:\raw_data` 的1000条TXT做过完整读取验证：全部为1340点、波数轴严格递增且没有非有限值。存在两套轻微不同的波数范围：800条为 `273.14–3746.91 cm⁻¹`，200条为 `274.55–3748.32 cm⁻¹`。本工具保留实际波数轴并写入CSV；后续建立统一特征矩阵时，应在清洗管道中插值到共同网格，而不是在人工标注阶段修改原谱。
