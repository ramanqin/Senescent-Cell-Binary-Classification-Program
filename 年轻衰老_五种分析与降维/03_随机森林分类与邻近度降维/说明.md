# 随机森林分类与邻近度降维

## 分类方法

- 使用401个预处理波数变量，不进行PCA或标准化。
- 外层5折评价，内层4折选择树深、叶节点最小样本数和分裂变量比例。
- 每个候选模型使用500棵树和类别平衡抽样权重。

## 当前分类结果

- AUC=0.9996，准确率=98.98%，平衡准确率=98.68%。
- TN=60、FP=0、FN=1、TP=37。
- 唯一误判为衰老31号，出现在外层第3折。

## 降维方法

统计任意两名受试者在500棵树中落入同一叶节点的比例，构建随机森林邻近度矩阵，再使用PCoA/MDS降至二维。该表示使用标签训练，属于监督式模型解释，不是新的验证成绩。

## 运行分类

```bash
pip install -r 代码/requirements.txt
python 代码/run_classification.py --input 数据目录 --output 新结果 --models random_forest --negative-class 年轻 --positive-class 衰老
```

## 运行邻近度降维

```bash
python 代码/visualize_embeddings.py --input 数据目录 --output 降维结果 --negative-class 年轻 --positive-class 衰老 --rf-model 新结果/random_forest/model.joblib
```

`结果`中包含分类指标、逐例预测、五折结果、波数重要性、邻近度坐标和相关图片。
